# Introducción a la Estadística

##  Categorías o Enfoques de la Estadística.

### Estadística descriptiva

Comprende los métodos utilizados para **organizar, resumir y describir la información recolectada**.

Utilizamos la estadística descriptiva cuando queremos conocer cómo se comportan los datos que hemos obtenido. Por ejemplo:

* **Rendimiento promedio:** calcular el rendimiento promedio del procesamiento de datos en un centro de cómputo durante un periodo determinado.
* **Clasificación de usuarios:** determinar cuántos usuarios existen según sus niveles de acceso o perfiles dentro de un sistema de información.
* **Tiempo de respuesta:** resumir el tiempo de respuesta de un servidor mediante valores como el promedio, el máximo y el mínimo.
* **Incidencias de soporte:** analizar el número de incidencias reportadas semanalmente para conocer su distribución e identificar posibles picos de fallas.

**En otras palabras, la estadística descriptiva nos ayuda a saber cómo son los datos que hemos recolectado.**

### Estadística inferencial

Comprende los métodos y técnicas utilizados para **obtener generalizaciones, realizar predicciones y hacer estimaciones sobre una población a partir de una muestra**.

La estadística inferencial se apoya en la **teoría de la probabilidad**, porque cuando trabajamos con una muestra existe incertidumbre sobre qué tan bien representa a toda la población.

Utilizamos estadística inferencial cuando, por ejemplo, queremos estimar o predecir:

* **La demanda futura:** estimar cuántos usuarios podría tener una plataforma digital utilizando como referencia el comportamiento histórico de acceso y uso.
* **El crecimiento del tráfico:** predecir cómo podría aumentar el tráfico de datos de una red a partir de sus registros históricos y las tendencias observadas.
* **La ocurrencia de fallos:** estimar la probabilidad de que un servidor presente una caída utilizando información obtenida de una muestra de registros.
* **El tiempo promedio de respuesta:** estimar el tiempo promedio de respuesta de una aplicación para todos sus usuarios utilizando mediciones realizadas únicamente durante determinados periodos o en ciertos nodos.

**En otras palabras, la estadística inferencial nos permite utilizar la información de una muestra para conocer, estimar o predecir características de una población.**

Como las conclusiones se obtienen a partir de una muestra y no de toda la población, existe un **grado de incertidumbre**. Los métodos de probabilidad permiten cuantificar o analizar esa incertidumbre y determinar qué tan confiables son las inferencias realizadas.
